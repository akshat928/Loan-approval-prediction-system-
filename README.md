# Loan Approval Prediction System

A machine learning system that predicts whether a loan application will be approved, explains which factors drive the decision, and serves real-time predictions through a Streamlit app that non-technical users can operate.

## Highlights

- **Feature engineering**: total household income, EMI at a 9% annual rate, EMI-to-income ratio, income left after EMI, and log transforms for skewed amounts
- **Model comparison**: Logistic Regression, Random Forest and Gradient Boosting, compared with stratified 5-fold cross-validation on ROC-AUC
- **Interpretability**: permutation feature importance on the held-out test set shows how much each input moves the prediction
- **One reusable pipeline**: imputation, scaling, encoding and the model are saved together in a single scikit-learn `Pipeline`, so the app can't drift from training
- **Streamlit app**: single-application form, batch CSV scoring with download, and a model insights tab

## Results

On the bundled dataset (2,000 applications, 68% approved):

| Model | CV ROC-AUC |
|---|---|
| **Logistic Regression** (selected) | **0.759 ± 0.020** |
| Random Forest | 0.747 ± 0.020 |
| Gradient Boosting | 0.732 ± 0.018 |

Held-out test set: **71.5% accuracy, 0.78 F1, 0.77 ROC-AUC**.

**What drives approval** (drop in ROC-AUC when the column is shuffled):

| Feature | Importance |
|---|---|
| Credit_History | 0.156 |
| ApplicantIncome | 0.094 |
| LoanAmount | 0.069 |
| CoapplicantIncome | 0.020 |
| Loan_Amount_Term | 0.016 |

Credit history dominates. After that, approval comes down to affordability: income against the size and term of the loan, which the engineered EMI features capture.

## Dataset

`data/loans.csv` is **synthetic** and generated by `scripts/generate_dataset.py`. It uses the same columns as the public [Loan Prediction dataset](https://www.kaggle.com/datasets/altruistdelhite04/loan-prediction-problem-dataset), including realistic missing values, so you can swap in the real data directly:

```bash
# Download train.csv from Kaggle, then:
cp ~/Downloads/train.csv data/loans.csv
python -m loan_model.train
```

| Column | Description |
|---|---|
| Gender, Married, Dependents, Education, Self_Employed | Applicant profile |
| ApplicantIncome, CoapplicantIncome | Monthly income (₹) |
| LoanAmount | Loan amount in thousands (₹) |
| Loan_Amount_Term | Term in months |
| Credit_History | 1 if the applicant meets credit guidelines, else 0 |
| Property_Area | Urban, Semiurban or Rural |
| Loan_Status | Target: Y (approved) or N (rejected) |

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m loan_model.train       # trains, compares models, saves to models/
streamlit run app.py             # opens the app at http://localhost:8501
```

A trained model is already included in `models/`, so you can run the app straight away.

## Using the model in code

```python
from loan_model.predict import load_model, predict_one

model = load_model()
predict_one(model, {
    "Gender": "Male", "Married": "Yes", "Dependents": "0", "Education": "Graduate",
    "Self_Employed": "No", "ApplicantIncome": 9000, "CoapplicantIncome": 3000,
    "LoanAmount": 100, "Loan_Amount_Term": 360, "Credit_History": 1, "Property_Area": "Semiurban",
})
# {'approved': True, 'probability': 0.9442}
```

Missing fields are allowed. They're filled the same way as during training.

## Project layout

```
app.py                        Streamlit app
loan_model/features.py        Feature engineering and preprocessing pipeline
loan_model/train.py           Model comparison, evaluation, feature importance
loan_model/predict.py         Load the model and score applications
scripts/generate_dataset.py   Synthetic dataset generator
data/loans.csv                Training data
models/                       Saved model, metrics.json, feature_importance.csv
tests/                        pytest suite
```

## Tests

```bash
pytest -q
```

The tests check the EMI calculation, missing-value handling, that training beats a 0.7 ROC-AUC baseline, that credit history is ranked the top driver, and that predictions respond to credit history the way they should.
